054 001 What is this? +

A voice-enabled RAG pipeline for the HH Goa 2026 shortlisting task. It transcribes speech, retrieves from an MSMARCO-XI mirror corpus using hybrid FAISS + BM25 retrieval, and answers with grounded generation — in Hindi or English.

054 002 Which dataset? +

ai4bharat/MSMARCO-XI. The bundled demo index runs on a curated mirror so it boots instantly and works offline; set HHGOA_USE_REAL=1 to build from the real streamed corpus.

054 003 Which STT provider? +

Sarvam saaras:v3 by default, with ElevenLabs scribe_v2 and Groq Whisper as alternates via HHGOA_STT_PROVIDER.

054 004 Why four chunking strategies? +

Naive fixed-size chunks break meaning. Fixed-overlap covers phrasing drift, sentence windows stay linguistically clean, semantic chunks keep one idea per unit, and metadata chunks self-describe — fusion benefits from all four.

054 005 How do you hit 200 ms? +

Everything runs locally — fastembed ONNX, FAISS + BM25 in-process, no vector-server round trips — with pre-warmed models, and an extractive fallback that skips the LLM entirely when no key is set.
